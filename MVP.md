# ghost — скоуп MVP

Полная спецификация — `SPEC.md`. Здесь только то, что делаем сейчас.

## Цель

Замкнуть цикл **звук собеседника → текст → локальная модель → ответ в невидимом оверлее** и получить первые реальные цифры латентности. Плюс один канал текста из браузера.

Распознавание — локальный whisper на GPU. Модель — `inception/mercury-2.5-preview` через routerai.ru (OpenAI-совместимый прокси OpenRouter).

## Входит

| # | Что | Зачем именно это |
|---|---|---|
| 1 | Оверлей: невидимый в захвате, поверх всех, click-through, не забирает фокус, watchdog affinity | Гейт осуществимости. Не работает — проект закрыт |
| 2 | PTT-хоткей → запись системного звука (WASAPI loopback) | Основной вход |
| 3 | whisper **пакетно** по отпусканию клавиши (не потоково) | Даёт текст. Потоковый режим — фаза 2 |
| 4 | routerai, стриминг ответа в оверлей | Замыкает цикл |
| 5 | Сброс контекста по хоткею | Требование из первого захода |
| 6 | CDP: текст редактора из браузера в контекст по хоткею | Второй по важности вход после звука |
| 7 | Метрики каждого шага, видны в оверлее | Без них фаза 2 настраивается вслепую |

## Не входит — и почему

| Что | Причина отсрочки |
|---|---|
| Спекулятивные запросы, потоковый ASR (LocalAgreement-2) | Политику спекуляций нельзя настроить, не имея метрик работающего цикла. Пакетный whisper по отпусканию клавиши уже даёт ответ примерно через секунду — этого хватает, чтобы пользоваться и мерить |
| VAD, режим `auto` | При PTT границы реплики задаёт клавиша. VAD нужен только для авторежима и микропауз |
| Микрофон, уточнения, `capture_self` | Отдельный канал, не нужен для замыкания цикла |
| UIA, скриншоты, области экрана | CDP покрывает основной случай live coding. Остальные пути каскада — когда будет ясно, где CDP не срабатывает |
| Anthropic, облачный ASR | Прод-бэкенды подключаются после того, как заработает цикл |
| Профили промптов, hot-reload, трей, diff-рендеринг черновика | Полировка. Не влияет на то, работает ли идея |
| Удалённый помощник | Отдельная подсистема, после основного цикла |

## Предпосылки сборки

Установлено 2026-09-03 на этой машине (`winget`). Нужны только для `whisper-rs`:

| Что | Зачем | Как ставилось |
|---|---|---|
| CMake 4.4.3 | сборка whisper.cpp | `winget install Kitware.CMake` |
| LLVM 22.1.8 | libclang для bindgen | `winget install LLVM.LLVM` |
| Vulkan SDK 1.4.357 | GPU-бэкенд ggml | `winget install KhronosGroup.VulkanSDK` |

Ни один из них не оказывается в PATH процесса сборки автоматически, поэтому пути
прописаны в `.cargo/config.toml` через `[env]` (`LIBCLANG_PATH`, `CMAKE`, `VULKAN_SDK`).

Там же `[build] target-dir = "C:/gt"`. Это не вкусовщина: вложенные пути
`ggml-vulkan/vulkan-shaders-gen-prefix/.../CMakeScratch/TryCompile-*/...`
перерастают предел MAX_PATH в 260 символов, и MSBuild падает с `FTK1011`.
Каталог сборки обязан быть коротким.

## Замеры и ограничения окружения

Проверено на машине 2026-09-03: i5-12600KF (10 ядер), 16 ГБ RAM, RTX 3080 (10 ГБ).

**Распознавание: только GPU.** Замер на окне в 30 секунд (whisper всегда кодирует
30 с независимо от длины реплики, поэтому мерить надо абсолютные секунды, а не
отношение к длительности аудио):

| модель | CPU, 8 потоков | Vulkan, RTX 3080 |
|---|---|---|
| `large-v3-turbo-q5_0` | 107 с | **0.20 с** |
| `small-q5_1` | 22 с | 0.10 с |

CPU-сборка через MSVC даёт примерно в 8 раз меньшую пропускную способность на
ядро, чем должна, — раскапывать это бессмысленно, потому что даже исправленная
CPU-сборка не давала бы требования Т1. Рабочая конфигурация: `large-v3-turbo` на
Vulkan. Он же точнее `small` на русском. CUDA Toolkit не нужен — Vulkan
достаточно, а установка легче на порядок.

**Модель рассуждает по умолчанию.** `inception/mercury-2.5-preview` без
дополнительных параметров сжигает 250+ токенов на размышление и при небольшом
`max_tokens` возвращает `content: null` с `finish_reason: "length"`. В запрос
добавлено `"reasoning": {"enabled": false}`: ответ за 0.6 с и ноль токенов
рассуждения. Параметр `effort: "low"` не помогает — рассуждение всё равно идёт.

**Диск.** C: был заполнен на 100%, из-за чего сборки падали с невнятными
ошибками. Каталоги сборки чистятся через `rm -rf C:/gt`.
